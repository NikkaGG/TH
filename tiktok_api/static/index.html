Рабочая панель

Автопубликация комментариев под чужими роликами недоступна через подтверждённый публичный API. Система автоматически готовит черновики; публикация выполняется в TikTok вручную. Браузерный поиск, если включён, экспериментальный.

Подключённые аккаунты

OAuth запрашивает профиль и свои публичные видео. Для подключения нужен одобренный TikTok app и зарегистрированный HTTPS callback.

Поиск и тематический отбор

Новый сценарий

Отбор основан на словах в описании и хештегах. Это не анализ изображения или звука.

Импортировать ролики

По одной строке: полный URL, затем табуляция и описание. Описание можно оставить пустым; такая запись не пройдёт тематический отбор без совпадений.

Очередь комментариев

Перед публикацией проверьте, что в обычной вкладке TikTok выбран нужный аккаунт. Отметка оператора не является подтверждением TikTok.

Фоновые задачи

Обновление каждые 8 секунд. При ошибке авторизации или проверке TikTok задача останавливается.
