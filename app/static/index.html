Аккаунт TikTok

Подключение TikTok

ПроксиsessionidГотово

Сначала укажите прокси для аккаунта. Затем перенесите вход из своего обычного браузера одной строкой.

Также подойдут host:port или login:password@host:port.

Войдите в TikTok в обычном Chrome и скопируйте одну строку по инструкции.

  1. Откройте TikTok и войдитеПерейдите на tiktok.com в своём Chrome. Убедитесь, что открыт нужный аккаунт.
  2. Откройте инструменты браузераНажмите F12 или Ctrl + Shift + I. Выберите вкладку Application (Приложение). Если её не видно, откройте меню ».
  3. Найдите sessionidСлева откройте Storage → Cookies → https://www.tiktok.com. В поле Filter введите sessionid и выберите строку с точным именем sessionid.
  4. Скопируйте значение и вставьте нижеДважды нажмите на ячейку в колонке Value (Значение), выделите её текст и скопируйте Ctrl + C. Нужно только значение, без слова sessionid.

Проверим вход через указанный прокси. Аккаунт появится в панели после подтверждения TikTok.

Другой способ входа

Можно войти в отдельном окне через тот же прокси. Вход через Google в таком окне может быть недоступен.
